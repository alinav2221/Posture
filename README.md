# Тренька

Упражнения из рилсов с таймером на одном экране. Работает без интернета.

Сохраняешь видео в телефон, отмечаешь в нём куски «начало/конец» (каждый кусок — упражнение), задаёшь таймер, собираешь тренировку. На тренировке кусок видео крутится по кругу, поверх — крупный таймер со звуком и вибрацией.

## Установить на телефон

1. Открой ссылку приложения в Chrome на Android.
2. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).
3. Запускай с иконки. Дальше интернет не нужен.

## Как пользоваться

1. **Видео** → «Добавить видео с телефона» — выбери сохранённый рилс из галереи.
2. **Упражнения** → «+ Упражнение» → выбери видео, промотай к нужному месту, нажми «Начало здесь», потом «Конец здесь». Задай таймер: по времени (работа / отдых / круги) или подходы (подходы / повторения / отдых).
3. **Тренировки** → «+ Тренировка» → добавь упражнения, поставь порядок и отдых между ними.
4. Нажми ▶ и тренируйся.

## Для разработки

Статический сайт без сборки: открыть папку любым локальным сервером.

```bash
npm test          # тесты движка таймера
npm run e2e       # сквозной тест в headless Chrome (нужны Chrome и ffmpeg)
```
