# vision.md — Тренька

## Зачем

Боль одна и конкретная: упражнения из рилсов в Instagram хочется делать под таймер, но на телефоне нельзя одновременно смотреть видео в инсте и держать запущенный таймер. Приходится переключаться, терять счёт, останавливаться.

Тренька решает это тупо и надёжно: видео упражнения и таймер на одном экране, без интернета, без аккаунтов и подписок.

## Для кого

Один пользователь — автор проекта. Телефон Android, Chrome. Тренируется дома по рилсам. Приложение личное, не для публикации в магазинах, но его может поставить себе любой, у кого есть ссылка.

## Ключевые сценарии

1. **Сохранить рилс.** Увидела упражнение в инсте → сохранила видео в галерею (любым загрузчиком) → в Треньке «Видео → Добавить с телефона». Видео живёт в телефоне, интернет больше не нужен.
2. **Нарезать без нарезки.** В одном рилсе часто несколько упражнений. Вместо монтажа — две отметки «Начало здесь» и «Конец здесь» прямо в приложении. Из одного видео получается несколько упражнений, файл не трогается.
3. **Задать таймер.** Два режима: «по времени» (работа / отдых / круги, как табата) и «подходы» (N подходов по M повторений, отдых по таймеру между ними; сам подход без отсчёта — нажала «Готово»).
4. **Собрать тренировку.** Несколько упражнений по порядку, отдых между ними. Или запустить одно упражнение прямо из библиотеки.
5. **Тренироваться.** Кусок видео крутится по кругу на весь экран, поверх — огромные цифры, цвет экрана меняется по фазе (работа / отдых / подготовка), звук и вибрация на смене этапа и отсчёт 3-2-1. Экран не гаснет. Пауза, пропуск, назад.

## Принципы

- **Офлайн — по умолчанию.** Всё хранится в телефоне. Сеть нужна один раз: открыть ссылку и установить.
- **Минимум действий во время тренировки.** Большие кнопки, одна главная кнопка, всё читается с пола с расстояния вытянутой руки.
- **Никакой обработки видео.** Только отметки времени. Это быстро, не ест место и не ломается на экзотических форматах.
- **Без сервера.** Статические файлы на GitHub Pages; нет бэкенда, нет данных у третьих лиц.

## Направление развития (идеи, не обещания)

- Экспорт/импорт данных (упражнения и тренировки без видео) — чтобы переносить между телефонами или бэкапить.
- История тренировок и простая статистика «сколько раз на этой неделе».
- Переопределение таймера на уровне тренировки (одно упражнение в разных тренировках с разным числом кругов).
- Голосовые подсказки («отдых», «последний круг»).
- Отдельная ссылка/QR для быстрой установки на новый телефон.
