# handoff.md — Тренька

Обновлено: 23.10.2026.

## Сделано (v0.1.0)

Полностью рабочее офлайн-PWA, проверенное юнит-тестами и сквозным прогоном в headless Chrome (эмуляция телефона 390×844).

- **Видео:** загрузка файла с телефона в IndexedDB, превью-кадр, длительность, переименование, удаление, показ занятого места, запрос постоянного хранилища.
- **Упражнения:** выбор видео (из сохранённых или новое), разметчик фрагмента (скраббер, «Начало здесь» / «Конец здесь», подстройка ±0.5 с, прокрутка куска по кругу), два режима таймера (по времени / подходы), заметка.
- **Тренировки:** название, список упражнений с порядком (▲▼), отдых между упражнениями, оценка длительности, дата последнего выполнения.
- **Плеер:** фрагмент видео на весь экран по кругу, фазы prepare/work/rest/set/between/done с цветом экрана, крупный таймер, прогресс-бар, пауза/пропуск/назад, «Готово» для подходов, звук (Web Audio) + вибрация, 3-2-1, экран не гаснет (Wake Lock), mute видео, полноэкранный режим, подтверждение выхода, экран «Ты молодец!».
- **Одиночный запуск** упражнения из библиотеки.
- **Настройки:** звук, вибрация, секунды подготовки, видео без звука, кнопка «Установить», состояние хранилища, версия и проверка обновлений.
- **PWA:** манифест, иконки (обычная + maskable), service worker с прекэшем и тостом «Есть обновление».
- **Тесты:** `npm test` (9 тестов движка), `npm run e2e` (сквозной сценарий, 12 проверок, 0 ошибок консоли).
- **Документация:** claude.md, vision.md, connectionguide.md, handoff.md, README.md.

## Не проверено на реальном телефоне

Всё тестировалось только в headless Chrome на Windows. На Android стоит проверить руками:
- выбор видео из галереи через `<input type=file accept="video/*">` и сохранение файла 20–60 МБ;
- автовоспроизведение фрагмента после «Старт» и смена видео между упражнениями;
- вибрация и звук сигналов при заблокированной громкости медиа;
- Wake Lock (экран не гаснет) в установленном приложении;
- `navigator.storage.persist()` — Chrome чаще разрешает после установки на экран.

## Известные ограничения и идеи

- Нет экспорта/импорта данных: при смене телефона всё заново.
- Нет истории тренировок (хранится только дата последней).
- Таймер задаётся на уровне упражнения; в разных тренировках нельзя переопределить.
- Кнопка «Назад» в редакторах не спрашивает про несохранённые изменения.
- Видео из инсты нужно сохранять в галерею сторонним способом — приложение не качает из интернета (и не должно).
- Безопасный ход при обновлении: не забыть повысить `CACHE` в `sw.js` и `APP_VERSION` в `js/version.js`.
